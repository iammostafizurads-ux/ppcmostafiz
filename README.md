# PPC Mostafiz - High-ROI Google & Meta Ads Consultant Portfolio

A modern, ultra-clean, high-converting single-page portfolio website built for **Mostafizur Rahman** (Brand: **PPC Mostafiz**), targeting `ppcmostafiz.com`.

## 🚀 Live Demo & Deployment

This project is built with static semantic HTML5, modern Tailwind CSS, Lucide icons, and lightweight vanilla JavaScript. It requires **zero build step** and can be deployed directly to Vercel, Netlify, Cloudflare Pages, or Hostinger.

### Deploy to Vercel (Instant)
1. Push this folder to a GitHub repository or drag-and-drop into [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Other** (Root directory: `./`).
3. Build Command: Leave blank (None).
4. Output Directory: Leave blank (None).
5. Click **Deploy**.

## 🎨 Design & Tech Architecture
- **Color Palette**:
  - Background: Deep Dark Navy & Slate (`#0b0f19`, `#070a12`, `#111827`)

  - Accent Growth Emerald: High-Converting CTA Emerald (`#10b981`)
  - Subtle Borders: Slate borders (`#1f293d`, `#2e3d5b`)
- **Typography**: Plus Jakarta Sans & Inter
- **Key Modules**:
  - Sticky glassmorphic navbar with active status indicator & mobile slideout drawer
  - High-impact hero with verified metrics counter and PPC live dashboard simulation card
  - 4 Core service pillars (Google Search, PMax & Display, Meta Ads, Conversion Tracking)
  - Interactive **Ad Waste & ROI Calculator** (live calculations of wasted budget and lead potential)
  - 4-Step Revenue Scaling Framework
  - 3 Results-driven case study cards with before vs. after metrics & category filtering
  - Authority comparison table (PPC Mostafiz vs. Large Agency vs. In-house Generalist)
  - Client testimonials with verified client markers
  - FAQ accordion covering objection handling
  - Direct conversion hub (Calendly strategy call booking + Free Google Ads Audit request form with confirmation modal)
  - Clean footer with quick links, social profiles, and back-to-top button

## 🛠️ Local Development
To preview the website locally on your computer:
1. Open terminal in this folder:
   ```bash
   npx serve .
   ```
   Or using Python:
   ```bash
   python -m http.server 3000
   ```
2. Open your browser and navigate to `http://localhost:3000`.
